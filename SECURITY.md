# Security and safety

The current software is an unsigned experimental preview. No version is represented as production-ready or hardware-accepted.

Report suspected vulnerabilities privately to the repository owner via GitHub private vulnerability reporting if enabled, or request a private reporting channel without posting sensitive details. Do not include personal archive paths, file contents, credentials, device identifiers, private network addresses, catalog databases, or burn journals in public issues or pull requests. Do not publish exploit details or secrets before the maintainer has had an opportunity to respond.

Never test optical recording with irreplaceable data or media. Keep independent backups and follow WINDOWS_ACCEPTANCE.md. No response time or support commitment is guaranteed.
