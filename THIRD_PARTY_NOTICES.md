## Public transition audit increment
The standard Windows CI now resolves a lockfile, inventories the Windows target dependency graph with the GUI feature enabled (including build/dev candidates), records declared license expressions, legal-file names and hashes, and potential embedded/native assets, then tests and builds with --locked. The inventory and crates.io lockfile are emitted to the public CI log without absolute runner paths or credentials. This is evidence for a subsequent license review, not a distribution license grant. It does not collect complete upstream notice texts or prove what is linked into the binaries. Existing public legacy preview assets remain unaudited; place the release in draft if supported, or otherwise restrict exposure with explicit owner authorization.
